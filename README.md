# 💰 Calculadora de Gorjeta

Projeto de estudo desenvolvido para praticar **JavaScript**, utilizando uma interface já estruturada em **HTML e CSS**.

A proposta do projeto é implementar a lógica em JavaScript para calcular automaticamente o valor da gorjeta com base no valor da conta e na porcentagem escolhida.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 🎯 Objetivo do Projeto

Este projeto foi criado com o objetivo de praticar:

* Manipulação de DOM
* Eventos em JavaScript
* Lógica de cálculo
* Validação de entrada do usuário
* Organização de código

O HTML e o CSS foram utilizados apenas como base visual, enquanto toda a lógica da aplicação está sendo desenvolvida em JavaScript durante o processo de estudo.

## 🔄 Status do Projeto

🚧 **Em desenvolvimento**

O projeto está sendo desenvolvido gradualmente, com commits frequentes para registrar o progresso da implementação da lógica em JavaScript.
